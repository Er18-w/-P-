# 批量 P 图网站：移动端编辑与撤销重做设计

## 目标

在不改变电脑端三栏工作方式的前提下，为手机端提供完整编辑体验。手机端和电脑端功能、数据与导出结果保持一致，均可上传图片、添加与编辑 Logo、创建组合、应用预设并批量导出。

同时补齐电脑端的键盘删除、全局撤销和重做能力，并让手机端复用同一套编辑历史。

## 范围

本次包含：

- 电脑端选中 Logo 后使用 Delete 或 Backspace 删除。
- 撤销、重做按钮及电脑快捷键。
- Logo 添加、删除、移动、缩放、透明度、显隐、组合、解散、自动定位和预设应用的历史记录。
- 图片亮度、对比度、饱和度、平滑和美白调整的历史记录。
- 手机竖屏底部导航、全屏画布、底部工具抽屉和横屏侧边工具面板。
- 手机触摸选择、移动、缩放、多选、组合及画布缩放。
- 手机端图片、Logo 库、组合和批量导出流程。

本次不包含：

- 文件上传、文件删除、Logo 库管理和导出操作的撤销。
- 改写现有抠图历史；抠图弹窗继续使用独立撤销。
- 更换现有渲染或导出技术。
- 引入新的第三方界面或手势库。

## 页面结构

### 电脑端

保留现有左侧任务、中间画布、右侧工具的三栏结构。顶部增加撤销和重做按钮，画布和右侧已有工具继续工作。

### 手机竖屏

- 顶部栏显示当前任务、撤销、重做和更多菜单。
- 中间画布占据剩余主要空间。
- 底部固定四个入口：图片、Logo、组合、导出。
- 点击入口后从底部弹出可滚动、可收起的工具抽屉。
- 上传图片后自动切到画布；添加 Logo 后自动选中。

### 手机横屏

画布位于左侧并尽量占满可用空间，当前工具面板显示在右侧。底部导航保留为紧凑入口，避免工具遮挡画布。

## 编辑交互

### 选择与移动

- 点击 Logo 选中，点击画布空白处取消选中。
- 按住选中的 Logo 拖动可移动。
- 手机触摸命中范围大于可见控件，但不会进入最终导出图片。

### 缩放

- 单个 Logo 显示四个适合触摸的等比例缩放角点。
- 锁定组合显示整个组合的外框和四个角点，移动和缩放作用于全部成员。
- 双指捏合缩放预览画布，双指拖动查看画布其他位置，不修改最终图片内容。
- 单指拖 Logo 与双指操作画布通过指针数量和命中对象区分，避免冲突。

### 多选与组合

- 电脑端继续支持空白处拖框多选。
- 手机端点击“多选”进入多选状态，逐个点击 Logo 增选或取消。
- 创建组合后成员锁定；只有解散组合后才能分别操作。
- 组合支持整体显示、隐藏、移动、缩放、删除和撤销恢复。

## 删除、撤销与重做

- 电脑端 Delete 和 Backspace 删除当前选中 Logo；若选中锁定组合，则删除整个组合。
- 光标位于 input、textarea、select 或可编辑文本区域时，删除键不触发画布删除。
- 抠图弹窗打开时，画布快捷键暂停。
- Ctrl+Z 撤销；Ctrl+Y 和 Ctrl+Shift+Z 重做。
- 撤销或重做后重新渲染画布、Logo 列表、组合列表、控制面板和按钮状态。
- 新编辑发生后清空重做栈。
- 拖动和连续滑块调整在操作结束时写入一次历史，避免一次动作产生大量记录。
- 历史记录设置合理上限，防止处理大图时长期占用过多内存。

## 状态与数据流

现有业务状态继续作为唯一数据源。编辑历史只保存可撤销字段的结构化快照，不复制图片像素、文件对象、Logo 图片数据或导出数据。

用户开始一次可撤销操作时记录操作前快照；操作完成后刷新界面。撤销时把当前快照放入重做栈，再恢复上一快照；重做执行相反流程。切换比例任务时，每个任务保留自己的编辑结果，历史记录仍按当前完整编辑状态顺序恢复。

移动端只是现有功能的另一种界面呈现，不建立第二套业务状态，也不复制导出逻辑。

## 异常与边界

- 没有选中对象时，删除键不执行操作。
- 没有可撤销或可重做内容时，对应按钮禁用。
- 删除组合后撤销，应恢复成员、组合关系、位置、尺寸和显隐状态。
- 切换图片、比例任务或设备方向时，当前选择与工具抽屉保持合理状态；不存在的选择会被清理。
- ZIP 下载失败不清空图片、Logo、组合或当前编辑结果，并显示可操作的重试提示。
- 浏览器不支持某些触摸事件时，保留现有按钮和滑块作为替代操作。

## 实施阶段

### 第一阶段：共用编辑基础

实现键盘删除、撤销重做状态、按钮、快捷键和现有编辑动作接入。先在电脑端验证所有历史动作以及输入框、弹窗等防误触边界。

### 第二阶段：移动端界面与触摸

实现响应式页面结构、工具抽屉、底部导航、触摸多选、组合操作、画布双指缩放及横屏布局，并复用第一阶段的历史记录。

### 第三阶段：集成验证与发布

验证桌面和移动端的完整流程，修复回归后一次提交并发布到现有 GitHub Pages。

## 验收标准

- 电脑端选中单个 Logo 或组合后可用键盘删除，并能撤销恢复、重做删除。
- 连续移动、缩放或滑块调整只需一次撤销即可回到操作前状态。
- 输入文字和使用抠图弹窗时不会误删画布 Logo。
- 手机竖屏可完成上传图片、添加 Logo、移动、缩放、多选、组合、应用预设和批量导出。
- 手机双指缩放只改变查看比例，不改变导出尺寸和 Logo 相对位置。
- 手机横屏工具不遮挡主要编辑区域。
- 电脑端原有布局、鼠标拖框、组合、预设、画布缩放和导出功能保持正常。
- Chrome/Edge 桌面端及常见 Android、iPhone 视口尺寸完成手工验证。
